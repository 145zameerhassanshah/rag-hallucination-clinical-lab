# Causes of LLM Hallucination

## Definition
An LLM hallucination is an unsupported, fabricated, or incorrect answer that may sound confident.

## Main Causes
1. Next-token prediction rather than direct truth lookup
2. Missing knowledge
3. Outdated knowledge
4. Ambiguous prompts
5. False premises
6. Long context
7. Retrieval failure
8. Poor chunking
9. Weak grounding instructions
10. Conflicting sources

## How RAG Helps
Question + Retrieved Evidence + Grounding Instruction → more evidence-based answer

RAG reduces risk; it does not eliminate it.
